# Lush Scent Guesser

A fan-made scent quiz game where players identify Lush-inspired products from progressively revealed ingredient clues.

## Language

**Player**:
A person playing a quiz session and optionally submitting a leaderboard name.
_Avoid_: User, account, profile

**Game Session**:
One Player's private, complete playthrough of ten rounds.
_Avoid_: Match, run

**Round**:
One product-guessing challenge inside a game session.
_Avoid_: Question, level

**Ingredient Clue**:
A revealed ingredient card that helps the player identify the product.
_Avoid_: Hint, tile

**Product**:
The answer the player is trying to identify in a round.
_Avoid_: Item, scent

**Leaderboard Entry**:
A submitted display name, score, and creation date shown on the leaderboard.
_Avoid_: User profile, account record

**Telegram Mini App**:
The full Lush Scent Guesser game experience opened inside Telegram.

**Inline Launch**:
Opening the Telegram Mini App from an inline invocation of the bot in a chat.
